## Template

```markdown
# ADR-NNN — Title

**Date:**
**Status:** proposed | accepted | superseded
**Deciders:** Master (+ architect)

## Context
[What forced the decision.]

## Decision
[What we chose.]

## Consequences
[What follows from it — good and bad.]
```
